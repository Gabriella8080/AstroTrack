# astrotrack: Characterising LEO Satellite Interference in Wide-Field Radio Astronomy

![CI](https://github.com/Gabriella8080/AstroTrack/actions/workflows/CI.yml/badge.svg) ![License](https://img.shields.io/badge/license-BSD--3-blue)

## Overview

`astrotrack` is a tool for characterising Low Earth Orbit (LEO) satellite interference in wide-field radio astronomy observations. While interferometric arrays are able to spatially localise and pinpoint satellite radiation in their beam patterns, wide-beam radiometers like REACH (de Lera Acedo et al. 2022) currently lack equivalent strategies for identifying satellite-generated contamination as they integrate the total sky power into a frequency spectrum. To address this instrumental limitation, `astrotrack` provides tools for processing Two-Line Elements (TLEs), selecting flyovers, analysing satellite properties, computing Doppler shifts, temporally comparing satellite metrics with generated Power Spectral Density (PSD) plots, and creating animations of satellite trajectories.

> **Accompanying Paper**: *'AstroTrack: A Tool for Characterising LEO Satellite Interference in Wide-Field Radio Astronomy'*, in preparation.

## Data Availability

Raw HDF5 files for PSD observation comparisons are proprietary to the REACH collanortion and are therefore not made publicly available. The publicly available 12,270 TLEs used in this work are provided in a [CSV file](data/TLE-catalogues/TLEs.txt) downloaded from [Space-Track](www.space-track.org) on 17:10:37 UTC 14 June 2025.


## `astrotrack` Installation

To install `astrotrack` from source, follow the instructions below:

```bash
conda env create -f environment.yml
conda activate astrotrack
pip install -e .
```

The package can then be imported using:

```bash
import astrotrack
```

`astrotrack` is recommended to be used with the provided Conda [environment](environment.yml).


## Quick Start

```python
from datetime import datetime
from astrotrack.preprocess import load_satellite_data

data = load_satellite_data(
    tle_file="LEO_TLE_file.txt",
    target_date=datetime(2025, 1, 18, 12, 25, 8),
    obs_len=3600, 
    traj_res=60,
    obs_lat=51.5,
    obs_lon=-0.1,
    R=2000,
    horizon_data="Horizon-Profile.csv", 
    satcon="STARLINK"
)
```

## Example Usage & Workflow

`astrotrack` is organised into five modules, where the package begins with initialising and structuring satellite Two-Line Element (TLE) data for analysis. The other subsequent modules build up on this to derive orbital properties, Doppler behaviour with respect to a ground-based experiment, animations, and enabling spectral associations.

<br>
<div align="center">
  <img src="docs/images/package-modules.png" width="600">
</div>
<br>

- [`preprocess`](): Loads and filters satellite TLE data provided by the user.
- [`satcon_properties`](): Filters, analyses, and visualises satellite trajectories as well as their metrics. 
- [`doppler_analysis`](): Evaluates Doppler shifts and detectability relative to a user-defined instrument's specifications.
- [`satcon_animate`](): Generates 3D trajectory animation GIFs.
- [`psd_analysis`](): Visualises satellite flyover properties alongside measured PSD data coincidential with satellite flyovers.

A detailed overview of all five modules, their key functions, and example usage is provided in a supplementary [document](docs/examples/examples.md).


A [demonstration](notebooks/astrotrack_demo/01_astrotrack_demo.ipynb), including usage of an example [horizon profile](data/horizon-profiles/REACH-horizon.csv) from the REACH experiment and a [TLE catalogue](data/TLE-catalogues/TLEs.txt) compiled from [Space-Track](www.space-track.org). A [baseline horizon profile](data/horizon-profiles/baseline-horizon.csv) corresponding to an idealised flat horizon is also provided. This can be used directly, or modified by the user to incorporate site-specific observational constraints.
